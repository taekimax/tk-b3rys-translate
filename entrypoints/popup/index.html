Local MLX
Standalone package installation Run Install.command from the mounted package, then load the installed extension in Chrome.
  1. Run Install.command from the DMG.
  2. Open chrome://extensions and enable Developer mode.
  3. Choose Load unpacked and select the web-translate extension folder.
  4. Reload the extension and refresh the page.
