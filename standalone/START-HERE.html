web-translate private preview

Offline Korean/English web translation for Apple Silicon Macs using the bundled Hy-MT2 7B model.

Unsigned preview: this package is not Developer ID signed or notarized yet. Do not disable Gatekeeper globally. If macOS blocks a file, use the file-specific approval in System Settings → Privacy & Security, and stop if that approval path is not available.

Install / 설치

  1. Open Install.command from this mounted disk image. It installs the prebuilt native host, MLX Metal library, bundled Hy-MT2 7B model, notices, and the unpacked extension into your user Library. No administrator password, Xcode, Swift, CMake, Homebrew, Node, Python, or network connection is required.
  2. Open chrome://extensions in Google Chrome and enable Developer mode.
  3. Choose Load unpacked, press Cmd-Shift-G, and select ~/Library/Application Support/web-translate/extension.
  4. Confirm the extension ID is pocbdkddmkkipegbinejlhjopmgimbdl.
  5. Open the web-translate popup. Hy-MT2 7B should say Ready. Reload the extension and refresh the page if Chrome asks.
  6. Run one translation while offline to confirm the local model is working.

설치 안내

  1. 마운트된 디스크 이미지에서 Install.command를 실행합니다. prebuilt native host, MLX Metal library, Hy-MT2 7B 모델, 고지 문서와 확장 프로그램을 사용자 Library에 설치합니다. 관리자 암호, Xcode, Swift, CMake, Homebrew, Node, Python 또는 네트워크가 필요하지 않습니다.
  2. Chrome에서 chrome://extensions를 열고 개발자 모드를 켭니다.
  3. 압축해제된 확장 프로그램을 로드합니다를 선택하고 Cmd-Shift-G를 눌러 ~/Library/Application Support/web-translate/extension을 선택합니다.
  4. 확장 프로그램 ID가 pocbdkddmkkipegbinejlhjopmgimbdl인지 확인합니다.
  5. web-translate 팝업을 열어 Hy-MT2 7B가 준비됨인지 확인합니다. Chrome이 요청하면 확장 프로그램을 새로고침하고 페이지도 새로고침합니다.
  6. 오프라인 상태에서 한 번 번역해 로컬 모델이 작동하는지 확인합니다.

Limitations / 제한

  • Private preview: Apple Silicon and macOS 14 or newer only.
  • Chrome Developer mode and manual Load unpacked are required for this private build.
  • The extension requests access to page content in order to translate it locally.
  • TranslateGemma models remain optional downloads and require their applicable terms review.
  • For removal and recovery, read UNINSTALL.md.
